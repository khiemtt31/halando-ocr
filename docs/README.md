# Documentation Index

Use this folder as the project handoff guide.

## Read In This Order

1. `../README.md`: project purpose, quick start, structure, and common commands.
2. `application-flow.md`: how upload, OCR processing, search, download, and delete work step by step.
3. `docker.md`: Docker Compose workflow, logs, rebuilds, resets, and troubleshooting.
4. `architecture.md`: components, code layers, data ownership, storage, database, and OCR strategy.
5. `test-ui.md`: browser UI for manually testing the local API.
6. `api.md`: endpoint list, roles, and response/error expectations.
7. `development-guidelines.md`: practical rules for safely extending the codebase.
8. `local-development.md`: concise local setup and verification runbook.
9. `structure-checklist.md`: implemented capabilities and files worth reviewing first.

## Documentation Rule

When behavior changes, update the matching document in the same change so future readers can trust the docs.
